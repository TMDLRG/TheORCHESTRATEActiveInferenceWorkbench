# `_local_guides/` — Generated beginner guides

A beginner-friendly companion to the curriculum in
[active_inference/](../active_inference/). Generated from the repo as the
primary source of truth.

## Contents

1. [01_SOURCE_INVENTORY.md](01_SOURCE_INVENTORY.md) — every repo file consulted
   for the beginner guide, with concept tags and confidence scores.
2. [02_CLAIM_EVIDENCE_MAP.md](02_CLAIM_EVIDENCE_MAP.md) — every major claim in
   the guide mapped to its repo source and a 1–5 confidence rating.
3. [03_BEGINNING_GUIDE_TO_ACTIVE_INFERENCE.md](03_BEGINNING_GUIDE_TO_ACTIVE_INFERENCE.md)
   — the deliverable. Beginner-friendly Markdown guide.
4. [04_VALIDATION_CHECKLIST.md](04_VALIDATION_CHECKLIST.md) — final audit
   against the SMART/PROVE criteria specified in the brief.

## Source-of-truth rule

Everything in this folder is **derivative**. The authoritative sources are
the upstream files in the repo (especially `active_inference/apps/...` and the
`priv/book/` extracts attributed to Parr, Pezzulo & Friston (2022) under
CC BY-NC-ND). When this folder and the repo disagree, the repo wins.
