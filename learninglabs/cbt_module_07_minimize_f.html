1 · Put the two faces together

Minimizing F means minimizing the gap

Both are exact descriptions of the same height F[q]:

  • Computable face: F = energy − entropy — built from the joint, no evidence. You can actually minimize this.
  • Meaning face: F = surprise + gap, with gap ≥ 0. This tells you what the minimum must be.

You can slide your belief to make F as small as possible. The surprise is a fixed number, so minimizing F means minimizing the gap — and the smallest the gap can be is zero, reached only at the posterior. So, forced:

argmin F = the posterior  ·  min F = −ln p(y) = the surprise

3 · The tag with teeth

Not every free energy is a safe bound

In our two-cause world you could minimize F perfectly, so min F equalled the surprise. Real worlds are too big to minimize perfectly — you land a little above the floor, where F is a ceiling over the surprise (still F ≥ −ln p(y)). A ceiling is useful — only if you never mistake it for the surprise itself. So every free-energy number carries a bound tag. Pick one and see where it can land relative to the true surprise:

Where each tag can land

The dashed line is the true surprise — the floor you proved. A tag is a safe stand-in only if it lands AT or ABOVE the floor. Find the one that can dip below — that’s the one never trusted as a bound.

▸ Go deeper — the Friston sign and MMP-BOUND-01 derivation
F is always reported with the Friston sign — an upper bound on surprisal, F ≥ −ln p(y). The tag says whether that number is a trustworthy stand-in (:exact) or only a loose ceiling. A number without its tag is not evidence — in the code, F is never a bare float but a value and its tag, and a bound is “guaranteed” only for :exact / :exact_mean_field. The one that bites: a :mmp form can fall below the surprisal — e.g. on a two-state chain where the true surprise is ln 2 = 0.693147, the :mmp value is ln 2 / 2 = 0.346574, under the floor — so it is never used as a bound or fed back as a belief (the rule MMP-BOUND-01).
